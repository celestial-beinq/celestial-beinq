# 💫 About Me:
Hey! I’m a frontend developer who enjoys building clean, functional, and easy-to-use web interfaces. I work primarily with Angular, TypeScript, HTML, CSS, Boostrap, Firebase and Supabase, focusing on creating applications that feel smooth, fast, and reliable for users.<br><br>I pay close attention to how things work,not just how they look. From structuring components properly to handling data efficiently, I like making sure everything behind the scenes is just as solid as the UI itself. I’m especially interested in building systems that are easy to scale and maintain over time.<br><br> I’m always sharpening my skills by working on real-world projects, experimenting with new tools, and improving how I write and organize code.<br><br>For me, it’s all about building practical solutions, solving problems, converting designs to realistics pages and being part of projects where what I create actually gets used and makes an impact.
